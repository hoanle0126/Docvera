Self-hosted PHP 8.2+ PDF & document processing platform, multi-mode SaaS billing engine, and versioned REST API (/api/v1/*). Zero third-party cloud document fees.

01 Getting Started

Docvera runs 22 document processing tools directly on your server inside isolated 0700 per-job directories. Every tool declares its required input MIME types, option schema, and fallback driver chain in src/Tools/ToolRegistry.php.

Path Purpose
public/Web server document root (index.php, .htaccess, CSS/JS assets).
config/app.phpCentral application, storage, security, and environment configuration.
src/Core framework, 22-tool registry, capability detector, drivers, auth, billing, and API controllers.
views/Server-rendered templates (home.php, tool.php, dashboard.php, admin.php, install.php).
bin/CLI utilities: bin/install, bin/migrate, bin/capabilities, bin/worker, bin/cleanup, bin/test.
storage/Writable runtime storage (storage/app/jobs, storage/app/staged, storage/app/database, storage/logs).

02 Installation (Web Installer & CLI Installer)

Option A — Guided Web Installer (Recommended)

  1. Upload the unpacked Docvera files to your server and point your web server's document root to /path/to/docvera/public.
  2. Visit https://your-domain.example/install in your browser.
  3. Review the live preflight check separating REQUIRED core checks from OPTIONAL CAPABILITY binaries.
  4. Configure Site Name, Application URL, Deployment Business Mode (saas, free_ads, or private), Database Engine (sqlite, mysql, or file), and Initial Administrator Credentials.
  5. Click Run Installation & Lock Installer. Docvera writes .env, generates a 256-bit CSPRNG APP_SECRET, executes idempotent schema migrations, seeds the 4 default plans, creates your admin account, and writes storage/app/database/.installed.lock.
Installer Lockout Guarantee: Once storage/app/database/.installed.lock exists, any subsequent GET or POST request to /install returns HTTP 403 Forbidden so no external visitor can re-run setup.

Option B — Headless CLI Installer

# Preflight readiness check only (exits 0 when all REQUIRED checks pass)
php bin/install --check-only

# Non-interactive installation
php bin/install \
  --app-name="Docvera Workbench" \
  --app-url="https://docs.example.com" \
  --business-mode="saas" \
  --db-driver="sqlite" \
  --admin-name="System Administrator" \
  --admin-email="admin@example.com" \
  --admin-password="ChangeMeImmediately!2026"

06 Admin Setup & 16 Operational Sections

Sign in with your administrator account and navigate to /admin. The Admin Console provides 16 dedicated sections:

  • Overview (/admin): Platform KPIs, storage footprint, active driver ratio, and security warning banner if default secret is active.
  • Business Mode (/admin/business-mode): Switch live between free_ads, saas, and private modes and toggle open registration.
  • Users (/admin/users): Create users, assign plans, change roles (user / admin), suspend accounts, or reset passwords.
  • Plans & Quotas (/admin/plans): Customize daily/monthly quotas, max file size, max pages, concurrent jobs, batch/OCR access, and retention windows.
  • Subscriptions & Payments (/admin/subscriptions, /admin/payments): Inspect subscription status and payment events.
  • Tools & Capabilities (/admin/tools, /admin/capabilities): Enable/disable individual tools, mark Pro tools, and inspect binary paths/versions.
  • Jobs, Queue & Storage (/admin/jobs, /admin/queue, /admin/storage): Inspect jobs, process queued jobs, and trigger expired file sweeps.
  • API Logs, Branding, CMS, SEO, Security & Updates: Full control over branding colors, CMS pages, SEO metadata, Stripe/PayPal keys, and update readiness.

07 Business Modes (free_ads, saas, private)

08 Users & Authentication Security

Docvera uses password_hash(..., PASSWORD_DEFAULT), automatic CSRF token rotation on login/logout, and brute-force rate limiting (maximum 10 failed login attempts per 15-minute window per IP or email before returning HTTP 429 Too Many Requests).

09 Plans & Entitlements

src/Entitlements/EntitlementService.php enforces a unified quota contract across both Web UI and REST API: daily_jobs_limit, monthly_jobs_limit, monthly_api_calls_limit, max_file_size_mb, max_files_per_job, max_pages_per_file, concurrent_jobs_limit, allow_ocr, allow_batch, and retention_minutes.

10 Payments & Webhook Security

Configure Stripe and PayPal credentials in /admin/security or .env. Webhook endpoints (POST /webhooks/stripe and POST /webhooks/paypal) verify cryptographic HMAC signatures and log every event idempotently by external_event_id.

11 Tool Configuration

In /admin/tools, administrators can enable or disable any of the 22 tools, set custom display titles or SEO descriptions, or mark specific tools as Pro-only. If a required system binary is missing, the tool automatically displays an honest Unavailable on this server badge.

12 File Retention & Ephemeral Privacy

Uploaded input files are purged immediately after job execution. Output artifacts are stored inside 0700 job directories, downloadable only via a session/owner-verified HMAC token, and can be deleted immediately via Delete File Now or swept automatically by php bin/cleanup.

13 Async Queue Worker (bin/worker)

Jobs submitted with async=1 (via Web or REST API) enter the queued state while retaining their concurrency slot until background processing finishes: 

php bin/worker --limit=25

14 Scheduler / Cron Setup

# Sweep expired job directories every 15 minutes
*/15 * * * * /usr/bin/php /var/www/docvera/bin/cleanup >> /dev/null 2>&1

# Process queued async jobs every minute
* * * * * /usr/bin/php /var/www/docvera/bin/worker --limit=25 >> /dev/null 2>&1

15 REST API (/api/v1/*)

Interactive documentation is built into your installation at /developers/api and /api/v1/openapi.json.

curl -X POST "https://your-domain.example/api/v1/tools/merge-pdf/jobs" \
  -H "Authorization: Bearer dcv_live_YOUR_API_KEY" \
  -H "Idempotency-Key: merge-req-001" \
  -F "files[]=@/path/to/part1.pdf" \
  -F "files[]=@/path/to/part2.pdf"

16 API Keys & Scopes

Users generate API keys in /dashboard/api-keys. Only the SHA-256 hash and 14-character prefix are persisted in the database. Supported scopes: tools:execute, jobs:read, jobs:download, and jobs:delete.

17 SEO, OpenGraph & Sitemap

Configure global title templates, meta descriptions, canonical base URL, and robots policy in /admin/seo. Dynamic XML sitemaps and robots directives are served at /sitemap.xml and /robots.txt.

18 Branding & CMS Pages

Customize your platform name, tagline, logo URL, primary color, and accent color in /admin/branding, and manage legal/informational pages (/privacy, /terms, /security, /about, /contact, /faq) in /admin/cms.

19 Backup, Upgrade & Rollback

# 1. Backup .env and database before upgrading
cp .env .env.backup-$(date +%Y%m%d)
cp -r storage/app/database storage/app/database.backup-$(date +%Y%m%d)

# 2. After replacing application files (preserving .env and storage/), run migrations:
php bin/migrate
php bin/capabilities
php bin/test

20 Troubleshooting & Security Recommendations

  • Web Root Isolation: Always point Nginx/Apache to public/ so .env, src/, and storage/ are outside the public web root.
  • Zero-Shell Execution: All external CLI binaries run through SafeProcessRunner with proc_open(..., ['bypass_shell' => true]) and strict timeouts.
  • Automated Self-Test: Run php bin/test (35 integration and security checks) after installation or server updates.
